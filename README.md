# My DankMaterialShell dotfiles

Personal configuration based on [DankMaterialShell](https://github.com/AvengeMedia/DankMaterialShell), with Hyprland, Kitty, GTK, Qt, and terminal customizations.

## Included

- DankMaterialShell settings
- Hyprland and DMS integration
- Kitty configuration and themes
- GTK/Qt appearance settings
- Fastfetch, btop, cava, and EasyEffects configuration

## Install

Install the required applications first, then from this repository run:

```bash
./install.sh
```

The installer backs up existing files to `~/.config-backup-YYYYMMDD-HHMMSS` and creates symlinks into this repository.

Hardware-specific monitor, input, and wallpaper paths may need adjustment on a different computer.
